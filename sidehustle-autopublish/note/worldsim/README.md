# AI世界観測所 / LYRA-001

## 現在の正本

同じ世界の離れた地域に、アルカ1,846人・ミレア2,214人・ヴァルド1,391人、合計5,451人が暮らす。
各人は固定IDを持ち、世帯、年齢、職業、技能、資産、価値観、性格、人間関係、知識・噂、目標、健康状態を保持する。

国家に「成長重視」「安定重視」のような固定人格は与えない。
政策は実在する住民から構成された制度の中で、各評議員の生活条件・価値観・職業利害・持っている情報・対人信頼から決まる。

## 世界の情報隔離

各国民はシミュレーションの全状態を読めない。
知識には必ず、観察、世帯、職場、近隣、友人、市場、制度などの情報源がある。
Turn 0では3国とも他国の存在を知らない。

地形、固定資源、深い過去の証拠、初期文明数はTurn 0前に固定し、SHA-256指紋を保存する。
作者都合で後から過去や資源を追加してクロスオーバーを作らない。

## 1ターン

1ターンは7日。
天候 → 問題の優先度 → 政策候補 → 市民評議員の投票 → 物質・健康・世帯への効果 → 食料収支 → 出生死亡 → 制度更新 → 探索・接触判定 → QA → 状態保存、の順で進む。

政策決定と結果計算は分離する。
同じ政策の連打にはクールダウンがあり、公共事業は開始・完了状態を持つ。
住民は加齢し、出生児は永続IDを持って世帯と関係網へ追加される。
死亡は本人を非活動化するだけでなく、世帯収入や近親者のストレスへ影響する。
評議会・執行役は任期または欠員で更新される。

## note公開

アカウント名は「AI世界観測所」。
ローンチ正本は `launch_v2/` の4本のみ。

公開後は毎週1ターン進める。
記事数をノルマにせず、対立した投票、意外な否決、制度交代、出生死亡、物質状態の大きな変化、探索・接触など、歴史として意味のある出来事だけを0〜2本/週公開する。

国別記事には、その国から知り得ない情報を書かない。
読者コメントは当面、世界内部の政策入力に使わない。

## 重要なQA

- 5,451人の一意ID・世帯整合
- 国内個人差が国平均差より大きい人格分布
- 孤立成人0
- Turn 0の越境知識・越境社会関係0
- 必須職種・食料基盤・資源残量の整合
- 政策クールダウン
- 出生ID重複なし
- 死亡ID重複なし
- 任期更新後も制度に実在住民のみ存在
- 60週間ストレステスト
- 公開前の読者可視URL検証

※すべて架空の国家・人物・統計・出来事であり、現実の国家・民族・政党をモデル化したものではない。
