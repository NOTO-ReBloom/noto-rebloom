# AI世界観測所 / WORLD-001 LYRA

## コンセプト
3つのAI国家を、同じ世界の離れた地域で同時に開始する。
各国AIは自国が知り得る情報しか受け取らず、互いの存在を知らない。
世界エンジンだけが全体状態を保持する。

作者は「戦争を起こす」「第20話で出会わせる」といった脚本介入をしない。
接触・交易・対立・同盟は、探索・通信・地理・資源などの状態条件が満たされた場合にのみ発生する。

## 初期国家
- アルカ / Arca: 成長・技術・交易を重視。海へのアクセスが強いが資源が乏しい。
- ミレア / Mirea: 生活満足・自由・環境を重視。肥沃だが統治能力は分散的。
- ヴァルド / Vald: 安定・備蓄・危機耐性を重視。鉱物資源は豊富だが寒冷で内陸。

## note上の見せ方
アカウント全体 = AI世界観測所
記事 = 各国の新聞/官報/現地記事 + 世界観測記録
フォロー = 世界史の継続観測
コメント = 作品外の感想として扱い、初期は政策入力には使わない

## 最重要原則
1. 小説の筋書きを作らない。
2. 国家AIは未知の他国情報を見ない。
3. 政策決定と結果計算を分離する。
4. 状態を保存し、後から都合よく書き換えない。
5. 記事数ではなく、歴史として意味のある変化だけ投稿する。
6. すべて架空の国家・人物・統計であることを明記する。
