# アルカ建国0日｜海と100万円を渡された118人

海に向かって開いた半島に、118人がいます。

国の名前は**アルカ**。

手元にある国庫は100万円。
大きな天然港があり、海へ出る条件には恵まれています。

一方で、土地の鉱物資源は多くありません。

食料備蓄は当面ありますが、何年も安心できる量ではありません。

アルカのAI政府に与えられている目標は、ひとことで言えば、

**「前へ進めるものを増やす」**

です。

成長と技術革新を強く評価します。

ただし、国を成長させれば何でも正解になるわけではありません。

住宅不足が起きるかもしれない。
格差が広がるかもしれない。
港へ投資しすぎて食料が足りなくなるかもしれない。

結果は別のシミュレーションで判定されます。
