# ノウハウ共有おじさん 調査・企画ベース

更新日: 2026-08-24

このディレクトリは、note・BOOTH・GitHub Pages向けの次回制作で直接読むための調査資産です。目的は、既存のAI業務改善、学生団体、イベント、協賛、NPO、卒論、就活、デジタル販売という軸を維持しながら、「一般論の解説」ではなく、競合が比較的薄い現場後半の実務を分かりやすく商品化することです。

## ブランドの約束

「複雑な実務ノウハウを、初めての人が今日ひとつ動かせる形まで分解する」。アカウント名は親しみやすい編集人格であり、年齢、職歴、経験年数、販売実績を意味しません。確認できない体験、肩書、売上、導入社数、改善率は書きません。

## ブルーオーシャンの定義

ここでいうブルーオーシャンは、検索需要や売上が証明済みという意味ではありません。2026-08-24時点の限定的な検索観測で、次の条件を満たす候補です。

1. 困りごとを公的資料または当事者向け資料で確認できる。
2. 一般的な解説はあるが、例外処理、停止条件、証拠、引き継ぎ、検品まで扱う実用品が相対的に少ない。
3. 無料noteだけでも小さな改善を完了でき、有料noteまたはBOOTHで編集可能な実装資産を追加できる。
4. 法務、医療、税務、安全などの専門判断を代替しない。

「競合がない」「必ず売れる」「検索されている」とは表現しません。競合の薄さは仮説であり、公開後の同齢PV、クリック、購入、売上で更新します。

## ファイル

- `source_registry.json`: 公式資料、プラットフォーム資料、直接競合の観測記録。
- `opportunity_map.json`: 40件の企画候補と無料・有料・商品への展開案。
- `next_topic_queue.json`: 次回制作に回せる上位24件。既存公開物・既存無料キューとの重複を避けた順序。
- `generation_contract.json`: タイトル、本文、CTA、根拠、人格、商品化の必須ルール。
- `research_snapshot_20260824.md`: 調査結果の圧縮メモと判断理由。

## 次回制作の読み順

1. `generation_contract.json` の禁止事項と合格条件を読む。
2. `next_topic_queue.json` から `status=ready_for_draft` を優先する。
3. 対応する `opportunityId` を `opportunity_map.json` で開き、対象読者、無料価値、有料差分、証拠IDを引き継ぐ。
4. `source_registry.json` の原典を公開直前に再確認する。制度・手数料・日付は必ず最新化する。
5. 公開後は同じ経過時間の一次指標で比較し、ブルーオーシャン仮説を昇格・維持・廃止する。

## 制作上の優先順位

1. AI導入後の検品、例外、停止、復旧、証拠管理。
2. 助成金・協賛・イベントの「終盤で必要になる証拠と分岐」。
3. 卒論・アンケートの再現性、変更履歴、除外条件、AI利用記録。
4. 学生団体・小規模NPOの権限、アクセス、世代交代、定例実務。
5. デジタル商品の公開後QA、版管理、問い合わせ境界、オファー検証。

一般的なプロンプト集、単なるタスク管理、一般的な学生団体引き継ぎ、抽象的な副業論は競合が多いため、一次指標なしには優先しません。
