使い方

①参加者数を入れる → ②受付条件と見守り比率を設定 → ③固定配置を入力 → ④最低人数と予備込み人数を確認。人員が足りない場合は、受付時間を伸ばす・受付を簡略化する・会場導線を減らすなどで再計算できます。
