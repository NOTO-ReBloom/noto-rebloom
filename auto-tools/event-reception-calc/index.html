計算の考え方

受付は、通常処理だけでなく例外対応で止まりやすくなります。このツールでは、例外率を平均処理時間へ加えたうえで、安全余力を差し引いて必要レーン数を算出します。

平均実効処理秒 = 通常秒 +（例外率 × 例外追加秒）
1レーン理論処理数 = 受付時間（秒）÷ 平均実効処理秒
実効処理数 = 理論処理数 ×（1 − 安全余力）
推奨レーン数 = 受付対象人数 ÷ 実効処理数 を切り上げ

レーンを増やす前にできること

受付時間を伸ばす、名簿を並べ替える、事前決済にする、参加証を事前準備する、通常受付と例外対応を分離する、案内係を受付処理から外す、といった方法でも必要人数を下げられます。

受付で行列を作りにくくする4原則

  1. 通常処理と例外処理を分ける：名前が見つからない人を通常レーンで長時間処理しない。
  2. 受付後の案内を別担当にする：受付担当が会場説明まで行うと処理時間が伸びます。
  3. 開始直前の集中を前提にする：平均到着ではなくピークを想定し、安全余力を残します。
  4. 切替条件を決める：「待ち列が10人を超えたら予備レーンを開く」など現場で判断できる条件を決めます。

FAQ

安全余力は何%がよいですか？

小規模イベントなら15〜25%から試すのが扱いやすいです。受付経験が浅い、参加者属性が多様、当日参加が多い場合は余力を大きめにしてください。

必要レーン数＝必要スタッフ数ですか？

必ずしも同じではありません。受付レーン以外に、列整理、例外対応、会場案内などを別担当にすると混雑を抑えやすくなります。

待ち時間そのものを予測できますか？

来場時刻の分布が分からないため、このツールは厳密な待ち時間予測ではなく、時間内に処理できる能力と余力を計算します。

入力内容は送信されますか？

いいえ。計算はこのページ内のJavaScriptだけで行い、入力内容を外部へ送信しません。
