使い方

提出日だけでなく、現在どこまで進んでいるかを入れるのがポイントです。すでに終わった工程は除外し、残った工程へ時間を配分します。作成後は、表示された日付をそのまま予定表へ移すのではなく、指導教員の確認日・調査対象者の都合・授業や就活など動かせない予定に合わせて微調整してください。

卒論を「書く作業」だけにしない

卒論は、テーマ設定 → 問い → 先行研究 → 方法 → データ → 分析 → 図表 → 執筆 → 指導コメント対応 → 最終確認という複数工程のプロジェクトです。本文の文字数だけを見ると、分析や修正の遅れを見落としやすくなります。

FAQ

提出まで1か月しかない場合も使えますか？

使えます。ただし残り日数が少ない場合は、各工程の日程がかなり圧縮されます。新しい調査を追加するより、今あるデータで成立する問いへ絞るなど、指導教員との優先順位確認を早めに行ってください。

先行研究は何本読めばいいですか？

本数だけでは決まりません。研究分野・問い・大学の基準により必要量が違います。このツールでは文献数を固定せず、「問いと分析を支える文献が揃っているか」を基準にしています。

自動生成された日程どおりに進めれば卒論は完成しますか？

保証はできません。研究には予期しない修正や追加調査が起こります。逆算結果は「何をいつまでに終えるか」を考えるための初期案として使い、指導教員からのコメントに応じて更新してください。

入力した研究内容は送信されますか？

いいえ。このページの計算はブラウザ内で完結します。研究テーマや個人情報を入力する欄も設けていません。

このツールは学位取得・提出受理を保証するものではありません。大学・学部・研究室の正式な提出要件を必ず確認してください。
