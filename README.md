# NOTO Re:Bloom Website｜2026年7月29日 現在地反映版

地域住民と学生が一緒に、能登の農地に人が再び関わるきっかけをつくるプロジェクト「NOTO Re:Bloom」の公式サイトです。2026年は本格的な農地再生の前段階として、泥ん子運動会を入口に、人の集まり方・関係の生まれ方・次年度へ残す記録を確かめます。

## 主なページ

- `index.html`：プロジェクト全体、2026年の位置づけ、現在の準備状況、学生企画メンバー募集
- `learn.html`：耕作放棄地・荒廃農地の基礎、全国データ、能登の復旧動向、2026年の実証方針
- `event.html`：9月20日開催予定の泥ん子運動会、確定事項と検討中事項、学生との共創
- `partner.html`：土地・移動・安全・記録など、現在相談したい協力内容
- `diagnosis.html`：56問・32タイプのRe:Bloom花タイプ診断

## 2026年7月29日の更新

- 「農地再生が完了した企画」ではなく、本格再生前の実証企画として説明を統一

- 一般向け大規模募集から、NOTO-REBOOST参加学生と地域住民・家族を中心とする設計へ変更
